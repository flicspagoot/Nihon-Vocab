# Vocabulary Tool

A command-line Japanese vocabulary quiz tool, devised using Pythong.

## Status

In early development stages, a short list with a quiz is put together.

## Current Features

- Quizzes Japanese words
- Checks answers regardless of capitalisation

## Planned Features

- Storage of words in JSON
- Organise it by JLPT level
- Shuffling and score tracking
- Tracking of failed words

## Requirements

- Python 3.14.7

## How to run

- python vocab.py

## Reasoning behind building

- I want to further my Japanese capabilities and this not only allows me to further development skills but further my Japanese.
